# StreamBun\n\nA free streaming site for movies and TV shows with no ads. Rebranded from P-Stream.\n\n## Quick Deploy\n\n[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fzerobun0%2Fstreambun)\n\n[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/zerobun0/streambun)\n\n**NOTE: To self-host, more setup is required. Check the original [P-Stream docs](https://docs.pstream.mov) for setup guides.**\n\n## Requirements\n\nYou'll need:\n- **TMDB API Key** - Get one free from [themoviedb.org](https://www.themoviedb.org/settings/api)\n- **Environment Variables** - Copy `example.env` to `.env` and fill in your keys\n\n## Running Locally\n\nType the following commands into your terminal / command line to run StreamBun locally\n\n```bash\ngit clone https://github.com/zerobun0/streambun.git\ncd streambun\ngit pull\npnpm install\npnpm run dev\n```\n\nThen you can visit the local instance [here](http://localhost:5173) or, at local host on port 5173.\n\n## Updating Your StreamBun Instance\n\nTo update your StreamBun instance you can type the below commands into a terminal at the root of your project.\n\n```bash\ngit remote add upstream https://github.com/p-stream/p-stream.git\ngit fetch upstream # Grab the contents of the new remote source\ngit checkout production\ngit merge upstream/production\n# * Fix any conflicts present during merge *\ngit add .  # Add all changes made during merge and conflict fixing\ngit commit -m \"Update StreamBun instance (merge upstream/production)\"\ngit push  # Push to YOUR repository\n```\n\n## Credits\n\nThis project is based on [P-Stream](https://github.com/p-stream/p-stream) - all credit to the original developers.\n
